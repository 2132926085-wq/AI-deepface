# FaceOps 集中人脸核验 · AntD Demo

纯前端演示（React + Ant Design + Vite），**不接真实接口**，数据保存在浏览器 `localStorage`。
对应线上演示站点部署的同一套页面（`face-demo-antd`）。

## 打开方式

```bash
npm install
npm run dev
```

构建为单文件：

```bash
npm run build
# 产物：dist/index.html（可直接打开，也可部署到任意静态服务器）
```

> 提示：纯前端演示，换浏览器/清缓存会回到种子数据；页面左下角有「重置演示数据」按钮。

## 主要功能

- **多租户隔离**：供应商之间人员、终端、记录互相隔离；VM 按绑定项目组看数据；全局管理员可看全部。
- **账号体系**：全局管理员统一创建全局管理员 / VM / 供应商管理员 / 终端账号，支持批量创建、账号类型筛选与颜色区分。
- **供应商 / VM 绑定**：一个供应商可绑定多个 VM；一个 VM 也可绑定多个供应商（供应商侧「对应VM」、VM 侧「供应商管理」页面互查）。
- **项目组与项目**：全局管理员创建项目组（可绑定 VM），VM 在项目组下建项目；人员加入项目时自动关联项目组，同一人员可加入一个项目组的多个项目，也可加入不同项目组。
- **人员库**：录入人员默认「未激活」，不直接显示照片（点进详情才显示照片、项目组、项目）；支持申请入项（预选人员）、编辑人员资料；供应商人员删除需先离项并经 VM 审批、确认已不在任何项目组。
- **人脸核验**：终端全屏核验页（今日已核验 / 未核验跳转）、看板（已核验 / 未核验按供应商/项目组/项目筛选并可跳转到对应记录）、人脸核验记录（多级联动筛选）。
- **申请中心**：入项 / 离项申请，选中人员后联动项目、自动去重；全局管理员可审批，也可直接拉人/移除。
- **审计日志**：全局管理员与 VM 可查看关键操作日志。

## 目录结构

```
src/
  App.jsx              # 布局、路由、菜单、登录态
  main.jsx             # 入口
  lib/
    helpers.js         # 纯函数：作用域、绑定关系、人员/项目操作
    mock-data.js       # 种子数据（首次访问写入 localStorage）
    ui.js              # 跨页面 UI 状态
  pages/               # 各功能页面
```
